BTC-D20 — Auxiliar Offline de Busca e Checksum

📖 Como utilizar esta ferramenta

Lance os dados D20 conforme as instruções oficiais do projeto BTC-D20 e informe os resultados nos campos D1, D2 e D3.

Busca normal de uma palavra

Para localizar uma palavra, preencha os três campos: D1, D2 e D3. Depois, clique em Buscar.

O sistema exibirá o número do registro e a palavra correspondente, seguindo a mesma organização da tabela do projeto.

Checksum para seed de 12 palavras

Após obter as primeiras 11 palavras conforme o método BTC-D20, faça o lançamento dos dados para a palavra de checksum.

Preencha somente os campos D1 e D2. Deixe o campo D3 vazio e clique em Buscar.

Serão exibidas as 16 palavras possíveis daquela linha. Essas palavras deverão ser testadas conforme as instruções oficiais do projeto para identificar a palavra de checksum válida.

Checksum para seed de 24 palavras

Após obter as primeiras 23 palavras conforme o método BTC-D20, faça o lançamento dos dados para a palavra de checksum.

Preencha somente o campo D1. Deixe os campos D2 e D3 vazios e clique em Buscar.

Serão exibidas as 256 palavras possíveis do bloco. Essas palavras deverão ser testadas conforme as instruções oficiais do projeto para identificar a palavra de checksum válida.

Importante

Esta ferramenta funciona localmente e offline em um navegador. Ela serve apenas como auxiliar de consulta e não substitui o manual, a tabela impressa ou o procedimento oficial do projeto BTC-D20.

⚠ Aviso Importante de Segurança

Esta ferramenta funciona totalmente offline e não realiza nenhuma comunicação pela rede.

No entanto, todas as palavras exibidas nesta página, incluindo as salvas no histórico, permanecem na memória da página (DOM) enquanto esta aba permanecer aberta. Extensões instaladas no navegador podem ter acesso a essas informações.

Para máxima segurança, utilize esta ferramenta em um ambiente confiável e offline, preferencialmente com todas as extensões do navegador desativadas.

Esta ferramenta foi desenvolvida para auxiliar a consulta das palavras BIP-39. Nunca utilize um navegador conectado à Internet ou com extensões desnecessárias ao manipular frases de recuperação reais.

Ao finalizar, clique em Limpar para remover os dados exibidos e, em seguida, feche a aba do navegador para liberar a memória da página.
